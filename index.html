Which Indian states are winning at rice, and who is being left behind?

An end-to-end analysis of 20 years of state-wise rice productivity (2005–06 to 2024–25): messy government Excel table → cleaned and modelled in SQL → insights and Power BI dashboard design.

The problem

Rice feeds most of India, but yield (kg per hectare) varies hugely between states. Raising low yields is a cheaper route to food security than adding land. I set out to answer: (1) how fast is national yield improving, (2) which states lead, lag and improve, (3) how stable is yield, and (4) where should productivity effort go first?

Pipeline

1 · Excel: clean

  • Removed title and index rows, unpivoted 20 year-columns
  • Handled “NA”, provisional flag, derived Total rows
  • Formula-driven summaries and a data-quality log

2 · SQL: model and analyse

  • Staging → star schema (3 dimensions + fact)
  • Views for BI, row-count validation
  • 8 queries: RANK, LAG, moving average, CTEs

3 · Power BI: communicate

  • Star-schema model with DAX measures
  • Growth, YoY, volatility, gap vs national
  • 4-page report: overview, states, regions, explorer

Key insights

    Recommendations

    • Target the low-yield, high-potential states first. Madhya Pradesh, Bihar and Rajasthan more than doubled or nearly doubled yield from a low base and still sit below the national average, so extension and irrigation support has proven traction there.
    • Prioritise stability, not just averages. States with high volatility (Mizoram, Madhya Pradesh, Bihar) need drought- and flood-resilient varieties and better water management.
    • Study the leaders. Punjab and Andhra Pradesh combine high yield with comparatively steady output; their practices are the benchmark for peers.
    • Fix the data. Several series have gaps or likely anomalies; standardised reporting would make benchmarking more reliable.

    SQL highlights

    -- Star schema: fact table at state × season × year grain
CREATE TABLE fact_rice_yield (
  state_id INT, season_id INT, year_id SMALLINT, yield_kg_ha INT,
  PRIMARY KEY (state_id, season_id, year_id),
  FOREIGN KEY (state_id) REFERENCES dim_state(state_id));

-- Rank states by long-run average yield
SELECT RANK() OVER (ORDER BY avg_yield DESC) AS rnk, state_ut, region, avg_yield
FROM vw_state_summary WHERE entity_type = 'State' AND years_of_data >= 15;

-- Volatility without vendor-specific functions
ROUND(100.0 * SQRT(AVG(1.0*y*y) - AVG(1.0*y)*AVG(1.0*y)) / AVG(y), 1) AS volatility_cv_pct

    Growth % = DIVIDE ( [Latest Yield (2023-24)] - [Base Yield (2005-06)], [Base Yield (2005-06)] )

Volatility CV =
VAR t = ADDCOLUMNS ( VALUES ( dim_year[crop_year] ), "y", [Avg Yield (Total)] )
RETURN DIVIDE ( STDEVX.P ( t, [y] ), AVERAGEX ( t, [y] ) )

    Method

    • Clean: removed title and index rows, unpivoted 20 year-columns into long format, converted “NA” to nothing, split the year label and flagged provisional data.
    • Model: one SQL table with a unique key on state, season and year, plus flags to prevent double-counting derived Total rows and the All-India aggregate.
    • Analyse: ranking, growth, volatility and season-gap queries using CTEs and window functions.
    WITH t AS (
  SELECT state_ut, crop_year, yield_kg_ha,
         LAG(yield_kg_ha) OVER (PARTITION BY state_ut ORDER BY start_year) AS prev
  FROM rice_yield WHERE is_total_row=1 AND is_all_india=0)
SELECT state_ut, ROUND(AVG(100.0*(yield_kg_ha-prev)/prev),2) AS avg_yoy_pct
FROM t WHERE prev IS NOT NULL GROUP BY state_ut ORDER BY avg_yoy_pct DESC;
